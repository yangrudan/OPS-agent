OPS Agent
老年人的智能守护者

专为老年人设计的 AI 智能助手，提供记忆管理、健康监测和天气服务， 让科技温暖每一位长者的生活。

🚀 快速开始 ⭐ GitHub

💡 核心功能

覆盖老年人日常生活的三大核心服务，让智能守护无处不在

🧠

记忆管理

帮助老年人记住重要信息，如用药习惯、亲朋好友的联系方式等。 采用向量数据库技术，支持模糊搜索，即使用简化关键词也能准确找到信息。

❤️

健康监测

通过蓝牙 BLE 协议与小米手环无缝集成，实时采集心率数据， 进行信息整合和分析处理，守护老人健康。

🌤️

天气服务

提供实时天气信息，根据地理位置自动获取天气预报， 帮助老年人合理安排出行和日常活动。

🔬 创新设计

融合前沿技术，打造最贴心的老年人智能助手

🗣️

自然语言交互

通过语音或文字与 Agent 交流，无需复杂操作

⌚

硬件集成

蓝牙 BLE 协议与 MiBand6 手环设备无缝对接

🔍

向量数据库

BAAI/bge 模型驱动，确保记忆检索的准确性

🎯

中心调度

ops-scheduler 智能协调各模块，高效响应

🌳 系统架构

基于 mofa-ai 框架构建的分布式智能 Agent 系统

关键数据流说明

OPS Agent 系统通过中心调度节点 (ops-scheduler) 协调各模块：

  1. 接收用户输入（语音/文本）
  2. 分发请求到记忆/天气模块
  3. 与智能硬件设备实时交互
  4. 整合信息并通过语音/文本反馈给用户

🚀 快速开始

只需几步，即可体验 OPS Agent 的强大功能

# 准备框架
pip install mofa-ai

# 安装依赖
pip install bleak  # 蓝牙 BLE 协议采集

# 克隆项目
git clone https://github.com/yangrudan/OPS-agent.git
cd OPS-agent/examples/ops-agent

# 配置 .env.secret 文件
# LLM_API_KEY=sk-xxxx
# LLM_API_BASE=https://api.moonshot.cn/v1
# LLM_MODEL=moonshot-v1-32k

# 启动服务
dora up
dora build ops_agent_dataflow.yml
dora start ops_agent_dataflow.yml

# 在另一个终端运行
mock-voice

关于 OPS Agent

OPS Agent（Old People's Agent）是基于 mofa-ai 框架打造的老年人智能助手， 遵循成为老年人守护者的初心，致力于提升老年人的生活质量与安全性。
